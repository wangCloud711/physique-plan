# 🏆 健体大赛完整备赛计划

一个为健体大赛（Physique）备赛量身定制的个人训练与饮食管理静态网站，使用纯 HTML / CSS / JS 构建，可直接通过 GitHub Pages 部署。

## 个人信息

| 项目 | 数值 |
|------|------|
| 年龄 | 35岁 |
| 身高 | 180cm |
| 体重 | 84kg |
| 体脂率 | 17〜20% |
| 训练经验 | 5年 |
| 目标 | 12〜18个月后登台参赛 |

## 功能页面

- **周计划总览** — 每周7天训练安排一览
- **周一〜周六** — 每天详细动作、组数、训练要点
- **手臂 & 三头专项** — 针对三头肌薄弱和手臂围度的专项方案
- **肘部康复指南** — 鹰嘴疼痛的动作调整与康复方案
- **每日饮食计划** — 四餐详细食材、克重、宏量营养素
- **补剂指南** — 按优先级排列的补剂建议
- **备赛路线图** — 四阶段完整时间线

## 本地运行

直接用浏览器打开 `index.html` 即可，无需任何构建工具或依赖。

```bash
git clone https://github.com/你的用户名/physique-plan.git
cd physique-plan
open index.html   # macOS
# 或
start index.html  # Windows
```

## GitHub Pages 部署

1. 将代码推送到 GitHub 仓库
2. 进入仓库 **Settings → Pages**
3. Source 选择 `main` 分支，目录选择 `/ (root)`
4. 保存后稍等片刻，网站即可通过 `https://你的用户名.github.io/physique-plan` 访问

## 后续维护建议

- 每月更新体重和体脂率进度
- 根据训练反馈调整动作和组数
- 肘部康复后更新卧推方案
- 备赛阶段调整饮食热量目标
